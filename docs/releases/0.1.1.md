# gafctl 0.1.1

- Publish gafctl and its library crates to crates.io. Install both executables
  with `cargo install gafctl --locked`.
- Fix the Bluetooth crate's Tokio feature declaration so it builds independently.
- Check Cargo archives before release and test registry installation on AMD64
  and ARM64, including server startup, HTTP, and shutdown.

The Debian packages, Linux archives, Docker image, Home Assistant app and
integration are also versioned 0.1.1. See the
[installation guide](https://github.com/mjc/gafctl/blob/v0.1.1/docs/installation.md).
