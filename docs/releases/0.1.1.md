# gafctl 0.1.1

- Install both executables from crates.io with `cargo install gafctl --locked`.
- Combine the Rust libraries into one `gafctl` package.
- Check the Cargo archive before release and test registry installation on AMD64
  and ARM64, including server startup, HTTP, and shutdown.

The Debian packages, Linux archives, Docker image, Home Assistant app and
integration are also versioned 0.1.1. See the
[installation guide](https://github.com/mjc/gafctl/blob/v0.1.1/docs/installation.md).
