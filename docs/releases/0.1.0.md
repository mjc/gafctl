# gafctl 0.1.0

First release of gafctl, a GAF Master Flow attic fan service, command line tool,
and Home Assistant integration.

## Original Wi-Fi Vent controllers

- Bluetooth support for ERV5SMT and EGV5SMT controllers with firmware 3.0.0.
- Temperature, humidity, controller fan state, thresholds, and timer readings.
- Automatic, Timer, and Off controls. Target temperature and humidity can be
  changed separately while preserving the other threshold.
- A saved timer duration of 0–360 minutes, defaulting to 360. Selecting Timer
  starts that duration; zero selects Automatic.
- Restoration of the previous mode after a timed run. The service must remain
  running and able to read the fan to restore Automatic.

## Home Assistant and clients

- HTTP integration with persistent device identity, reconfiguration, and bounded
  cached readings during temporary proxy outages.
- MQTT discovery, readings, and controls. Each device uses either HTTP or MQTT
  for its Home Assistant entities.
- `gafctl` and `gafctl-server`; `gafctl server` launches the sibling server.
- HTTP and MQTT controls require acknowledgement and matching readback. Sent
  device writes are not automatically retried.

## Installation

- AMD64 and ARM64 Linux Debian packages and binary archives.
- Docker Compose, Nix packages, a NixOS service module, and a Home Assistant OS app.
- Home Assistant integration through HACS as a custom repository or manual copy.
- Native ARM64 macOS command line support through Nix or a source build.

See the [installation guide](../installation.md) for setup. The HTTP API has no
login; restrict it to trusted clients. Original controllers need Bluetooth on the
server host, with BlueZ on Linux. The integration requires Home Assistant 2026.9.4
or newer.

QuickConnect support is experimental, has not been tested with a live controller,
and is read-only by default. Fan airflow is not measured; the original controller
reports its own on/off flag.
