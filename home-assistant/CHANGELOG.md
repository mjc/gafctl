# Changelog

## 0.1.0

- HTTP and MQTT service for original GAF Wi-Fi Vent controllers.
- Experimental QuickConnect support, with settings writes disabled by default.
- Persistent device identities and access to the host's BlueZ service.
- Automatic, Timer, and Off controls for original controllers, with adjustable
  temperature, humidity, and timer duration. Mode and number controls share
  Home Assistant's Controls section.
